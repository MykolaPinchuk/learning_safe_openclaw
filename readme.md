## Introduction

The objective of this codebase is to build an interactive learning app to  learn Openclaw and its best practices from security standpoint. All materials are in input_reports dir.

## Current Status

- Product direction is captured in `docs/prd.md`.
- Implementation decisions are captured in `docs/engineering-spec.md`.
- The current prototype-first testing guide is in `docs/prototype-testing.md`.
- A crude local prototype is available in `prototype/index.html`.
- The implemented app lives at the repo root and runs with Vite.

## Run The App

```bash
npm install
npm run dev
```

## Test The App

```bash
npm test
npm run test:e2e
```
